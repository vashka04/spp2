# Обновлённый парсер метрик Джилба

Запуск: `python parser.py`. Требуется Python 3 и PHP CLI; `tokenizer.php` должен лежать рядом с `parser.py`.

Правила подсчёта:
- `if` и каждый `elseif` считаются условиями; `elseif` увеличивает уровень вложенности как вложенный `if`.
- `else` не считается.
- `switch` сам по себе не считается; каждый `case` учитывается как вложенное условие. `default` не считается.
- `try/catch` игнорируется.
- Тернарный оператор `?:` игнорируется.
- `for`, `foreach`, `while` учитываются по одному. `do...while` считается одним циклом по завершающему `while`, `do` отдельно не учитывается.
- Относительная метрика сохранена как абсолютная сложность / число разделителей `;`; проверьте, соответствует ли это формуле из вашей методички.
